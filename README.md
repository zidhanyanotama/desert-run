# 🏜️ Desert Run

A 2D platformer game developed using **Unity** and **C#**, inspired by classic side-scrolling platform games.

## 🎮 About the Game

Desert Run is a 2D platformer set in a desert-themed environment. Players must navigate through different levels, overcome obstacles, avoid enemies, and collect items to progress through the game.

The main objective is to find keys scattered throughout the levels and use them to unlock doors leading to the next stage.

## 🕹️ Gameplay Features

- **Player Movement:** Navigate through the environment using movement and jumping mechanics.
- **Obstacles:** Overcome various obstacles throughout the levels.
- **Coin Collection:** Collect coins scattered across the environment.
- **Enemies:** Avoid enemies while progressing through each level.
- **Key & Door Mechanic:** Find keys to unlock doors and access the next level.
- **Level Progression:** Complete objectives and advance through multiple levels.

## 🛠️ Built With

- **Game Engine:** Unity
- **Programming Language:** C#
- **Platform:** Windows
- **Game Type:** 2D Platformer
